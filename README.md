## 🛠️ My Open-Source Unity Toolchain

I build and maintain tools that solve architecture and performance bottlenecks in Unity:

- 🚀 **[Fast IoC](https://github.com/sgonzalezrozo/unity-fast-ioc)**: A dependency injection framework for Unity 6 with edit-time code generation and no runtime reflection. Benchmarked on low-end mobile devices in IL2CPP.
- 🎬 **[UI Tweens](https://github.com/sgonzalezrozo/unity-ui-tweens)**: An allocation-conscious, ECS-based animation engine for Unity UI, built on LeoECS.
- 🧩 **[UI Foundations](https://github.com/sgonzalezrozo/unity-ui-foundations)**: Small uGUI building blocks for strict MVC that replace Unity's standard Button and Toggle.
- 🤖 **[Unity Architecture Agents](https://github.com/sgonzalezrozo/unity-architecture-agents)**: Strict MVC architecture rules, Roslyn analyzers, and verification scripts for AI coding assistants (Claude Code, Cursor, Copilot).
